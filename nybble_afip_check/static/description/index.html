🇦🇷 Nybble AFIP Connection Check

Version 18.0.1.0.0 Odoo 18 Enterprise Argentina Localization

📋 Overview

Prevents Point of Sale freezing when AFIP (Argentina Tax Authority) web services are unavailable. This module pre-validates AFIP connectivity before issuing electronic invoices, providing instant feedback to cashiers instead of waiting for connection timeouts.

⚠️ Problem Without This Module:
When AFIP servers are down, the POS hangs for up to 60 seconds waiting for a timeout, causing frustration and delayed customer service.
✅ Solution With This Module:
Pre-checks AFIP connectivity and immediately shows a user-friendly error message with instructions to create tickets without electronic invoicing.

✨ Features

  • Pre-validates AFIP connectivity before issuing electronic invoices
  • Shows actionable error messages when AFIP is unreachable
  • Suggests creating tickets without electronic invoice as fallback
  • Prevents long timeout waits and improves cashier experience
  • Comprehensive logging for troubleshooting
  • Zero configuration required - works automatically
  • Fully translated to Spanish

🔧 Technical Details

The module extends account.move._l10n_ar_do_afip_ws_request_cae() to pre-check connectivity using journal._l10n_ar_get_afip_last_invoice_number(). If AFIP doesn't respond, it raises a ValidationError with a user-friendly message.

📦 Dependencies

  • point_of_sale - Odoo POS module
  • l10n_ar_edi - Argentina Electronic Invoicing (Enterprise)

🚀 Installation

  1. Copy module to your Odoo addons directory
  2. Update apps list in Odoo
  3. Search for "Nybble AFIP Connection Check"
  4. Click Install

💡 Usage

No configuration needed! The module works automatically in the background. When AFIP is down, users will see a clear error message with instructions.
